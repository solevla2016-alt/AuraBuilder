B|🆕 5.1.1. Доступность палитры: контраст и цветовые роли
P|Проверка палитры «Golden Sand» по WCAG 2.1 выявила нарушения: акцентный и вторичный цвета не пригодны для текста и границ на песочном фоне. Измеренные значения (расчёт по формуле относительной яркости):
TABLE
ROW|Сочетание ||| Контраст ||| Оценка
ROW|Акцент #D4B896 на фоне #F5EFE0 ||| 1.65:1 ||| Не проходит (требуется ≥ 3:1 для UI, ≥ 4.5:1 для текста)
ROW|Вторичный #C9B896 на фоне #F5EFE0 ||| 1.70:1 ||| Не проходит
ROW|Мягкий текст #7A6F58 на фоне #F5EFE0 ||| 4.32:1 ||| Проходит только для крупного текста
ROW|Текст #3A3428 на фоне #F5EFE0 ||| 10.76:1 ||| AAA
ROW|Текст #3A3428 на панели #FBF6E8 ||| 11.43:1 ||| AAA
ENDTABLE
NEW
B|Требование: акцентный цвет не используется для текста, подписей и тонких границ. Вводится отдельная пара токенов:
TABLE
ROW|Токен ||| HEX ||| Назначение ||| Контраст на #F5EFE0
ROW|accent-surface ||| #D4B896 ||| Заливка кнопок, свечение Aura, Backlight, акценты графики ||| — (не текст)
ROW|accent-text ||| #7A5C30 ||| Текст на кнопках, ссылки, подписи активных элементов ||| 5.38:1 (AA)
ROW|accent-text-strong ||| #6B4F28 ||| Заголовки акцентных блоков, hover-состояния ссылок ||| 6.60:1 (AAA)
ROW|muted-text ||| #6B6250 ||| Вторичные подписи, подсказки ||| ≥ 4.5:1 (AA)
ENDTABLE
NEW
B|Обязательные требования по доступности (дополнение к п.5.2):
BL|0|Контраст обычного текста — не ниже 4.5:1, крупного (≥18px или ≥14px полужирный) — не ниже 3:1
BL|0|Контраст границ и состояний фокуса — не ниже 3:1
BL|0|Все интерактивные элементы доступны с клавиатуры; drag-and-drop дублируется операциями перемещения клавишами
BL|0|Видимый фокус на всех элементах (не удалять outline без замены)
BL|0|Подписи и aria-роли для всех контролов; поддержка скринридеров
BL|0|Режим prefers-reduced-motion: отключение анимации «дыхания» (п.5.2) и переходов
